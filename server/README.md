# 捐款通知啟用

1. 用協會 Google 帳戶建立獨立 Google Apps Script 專案，把 `donation-notification.gs` 貼入。不要覆蓋商城程式。
2. 部署為網頁應用程式：執行身分選部署者，存取權選任何人。依 Google 提示授權寄送電子郵件。
3. 把部署的 `/exec` 網址填入 `js/config.js` 的 `DONATION_SCRIPT_URL`，然後將網站檔案更新至主機。
4. 用測試資料提交一次，確認畫面回報成功且協會 Gmail 收到「【測試】CTTDA 捐款通知」。測試匿名提交、選填資料與個資勾選驗證。
5. 正式啟用前更新 support.html 的銀行帳戶及示範說明；在 Apps Script「專案設定 → 指令碼屬性」設定 LIVE_DONATIONS=true，移除信件測試標記。

這個流程在訪客按提交後自動寄信，不會監測銀行入帳，也不會自動扣款。真正的入帳通知需銀行或金流服務提供可驗證的通知介面。

個資不存入網站 localStorage 或試算表，僅寄至協會電郵。協會須管理信箱權限、訂定保留期限，並依當事人要求處理資料。公開端點已加每小時 30 封限制與 10 分鐘相同資料去重；正式營運若遭濫用，需另加伺服器驗證的 CAPTCHA。Google Mail 配額或網路故障會回報失敗，不會顯示假成功。
